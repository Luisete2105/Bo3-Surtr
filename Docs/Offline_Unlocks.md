# Offline unlocks (mega gums + super EE reward)

Surtr's release includes a **`Bo3 Offline Files`** folder that unlocks mega gums and the super Easter Egg reward while playing offline. It takes less than a minute.

## What you need

- The Surtr release zip (from the [Releases](https://github.com/Luisete2105/bo3-surtr/releases) page).
- Your Black Ops 3 game folder (the one that contains `BlackOps3.exe`).

## Steps

1. **Download and extract** the Surtr release zip.
2. Open the extracted folder and go inside **`Bo3 Offline Files`**.
3. **Copy everything** inside the folder (4 files: `stats_zm_offline_0.cgp`, `stats_zm_offline_1.cgp`, `loadouts_zm_offline_0.cgp` and `loadouts_zm_offline_1.cgp`).
4. Paste them inside the `players` folder of your game:

   ```
   C:\Program Files (x86)\Steam\steamapps\common\Call of Duty Black Ops III\players
   ```

   > **Tip:** if the `players` folder doesn't exist, launch the game once (it creates it), close it and then paste the files.

5. Done! Launch the game with **`Launch Game + Load Mod.bat`** and the mega gums + super EE reward will be active on offline mode.

> **Note:** these files replace your offline zombie stats and loadouts (that's what unlocks the gums). If you already play offline and care about your current stats, back up the `stats_zm_offline_*` and `loadouts_zm_offline_*` files in `players` first.
