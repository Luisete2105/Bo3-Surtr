# Splits

Surtr registers **LiveSplit auto-splits**. A split can be enabled with the
`HuD` command followed by the split name (any of its valid names), or all
common Easter Egg splits at once with `Activate_Common_EE_Splits`.

Splits come in two types:

* **Easter Egg (EE) splits** – fire as you progress through an Easter Egg.
  These are grouped first, per map.
* **Normal splits** – general progress splits that are not tied to an Easter
  Egg. These are grouped last.

The map each split belongs to is used to register it, so a split only exists
while that map is loaded.
